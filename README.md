# Digital Hunters Landing Page

A modern and fully responsive gaming studio landing page built using HTML5 and CSS3.

## About The Project

This project is a futuristic game studio landing page focused on responsive layouts, clean positioning, and modern UI design. The website includes a hero section, responsive navbar, project showcase cards, workflow section, stats section, and footer with smooth hover effects and adaptive layouts.

## Technologies Used

- HTML5
- CSS3
- Flexbox
- Media Queries
- CSS Animations
- Responsive Design

## Features

- Fully responsive layout
- Flexbox-based structure
- Mobile navigation menu
- Responsive media queries
- Smooth hover animations
- Modern gaming UI design
- Reusable component styling
- Clean typography and spacing

## Design Goals

- Create a scalable responsive layout
- Improve flex positioning behavior
- Maintain consistency across devices
- Build a clean and modern interface
- Ensure smooth mobile responsiveness
